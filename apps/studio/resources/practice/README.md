# 今晚，让春天亮起来 · 示例作品素材

春灯放映馆明天关闭。主人公与成年鲸尾姑娘澜汐、银发龙族绮白、橙发放映员绯书，在最后一个春夜为旧街筹备一场露天放映。九个场景包含共同序章、筹备、放映、三条人物路线与三段普通后日谈；三条路线保留 `spring-whale`、`spring-dragon`、`spring-letter` 结局身份。

`manifest.json` 定义采用闭包：六张背景、三张剧情 CG、五首原创 Opus、39句日语成品配音、两段原创效果声、三张天气纹理、四支 Motion Canvas OP／ED、十八张角色差分、三张头像、十五个 SVG、四张独立主页图及影片作者依赖。五首音乐与四支影片均关联精确插件作者文档，音乐循环区来自实际渲染记录。

三位角色各有13句日语对白，覆盖主线、路线、结局和后日谈。`sources/voice/adopted-ja/lines.json` 保存中日台词对照。语音默认及支持语言为日语；三位路线角色保持无语音制作预设，作者可在自己的制作环境配置制作参数。中文剧本、界面与角色名保留。玩家角色默认名为“玩家”，无声、无头像及立绘；作品允许改名，上限8个可见字符，首次及正篇结束后确认姓名。姓名确认在OP前完成，未完成正篇重新开始时沿用当前姓名。玩家说出口的话用角色对白，内心与观察用第一人称旁白。

作品分别支持作者未读／已读正文样式，样例只用颜色展示：未读继承原正文色，已读使用清晰的暖灰 `#c6b8aa`，字体和字号保持一致。Player 在正向推进正式成功后记录离开句已读；全文显示、停留、同句续页和存读档保持原状态，读旧档继续查询当前长期记录。

筹备片段先播放 BGM，再启动循环雨声和 7.2 秒铃声。铃声播放 1.5 秒后，剧情按雨声 soundId 停止雨声；BGM 与铃声继续，铃声随后自然结束。共同线还展示独立背景 GCA 及停止、2600ms 单次轻微呼吸、500ms 人物移动在 200ms 时切换差分、三人重叠和 z 调整；共同放映展示三天气中的雪与樱花、六滤镜、富文本及 NVL。所有背景、CG、音乐和影片使用真实鉴赏条目，成功显示或播放后解锁。

三位角色各有日常、微笑、认真、惊讶、害羞、低落六个共同差分，绑定已有立绘的精确版本和头像裁剪；剧情用 `characterDifference` 同步头像与立绘，退场对白和存读档保留表情。`sources/images/avatar-crops.json` 记录原图像素坐标，各表情沿用同一归一化范围，立绘保持完整原图。`avatars/*-head.png` 保留为角色默认回退头像，从 neutral 立绘裁出头肩，`tools/artwork/prepare-practice-avatars.mjs` 可重建；共同差分裁剪沿用已有图片。

剧情BGM采用65%指令音量，重点语音采用90%，雨声38%、铃声60%。玩家各音量分类继续独立控制；默认关闭对白压低BGM。五曲采用−18 LUFS播放版本、Opus 128 kbps；制作源随本目录保存，原始 WAV、公开制作来源摘要和整定 WAV 母带单独归档于仓库 `assets/generated/practice/music/`，轻量分发只收录实际播放成品及可编辑来源。

Flow 使用四个 `firstUnlock` 节点及三个配置明确初值的独立回想节点，边只负责展示路线。普通后日谈各自绑定对应结局，约一至两分钟；解锁后整卡单击每次从头，显式读档恢复中段，独立资料与正篇继续位置保持分离。正常结束返回标题且不新增正篇结局。样例保留三路线、Flow 布尔变量和后日谈 characters 目录，移除关系入口、relations 页面、关系 HUD、三个关系变量及加分。

标题采用独立的放映馆回忆墙背景、两张合照与透明艺术字，系统页使用浅色晴空背景；图标来自普通 SVG 素材槽，春灯配色通过可编辑的基础页面 CSS 实现。页面样式随页面加载，剧情按需应用的具名样式继续独立控制。

[覆盖定位](coverage.md)列出作者入口、剧情定位及验证边界；[来源索引](source-index.md)记录采用版本与实际来源。授权的剧情、图片、音乐、日语成品配音及影片使用CC BY 4.0；第三方纹理、字体与生成工具条件见[许可范围](licenses/README.md)。

Studio 创建示例时通过 M04 导入采用资源，通过 M02 事务创建四名角色、九个场景、鉴赏、Flow、后日谈入口与作者源。创建过程保留作者填写的作品名称。每份新作品重新分配内部身份，作者已创建的副本保留自己的内容。


主页采用放映馆回忆墙：背景、两张三人合照和原名透明艺术字作为四个独立素材层，由普通公开页面部件承载，真实菜单保留语言、动作与解锁行为。`manifest.home`及`sources/images/home-generation.json`登记2026-10-28内置ImageGen输出、角色参考、实际尺寸与透明检查；原始PNG即当前采用文件。作者给副本改名后可在页面设计器替换标题图。

实际作品把来源索引、主页生成记录和第三方完整许可汇集为 `SAMPLE-MEDIA-NOTICES.txt`，作为回忆墙图片的许可附件随M04资源闭包保存。M02备份、独立恢复和M11发行均保留该附件；作者在素材详情中可查看其来源说明，官网另提供可读副本。
