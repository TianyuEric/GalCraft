# 工作区与作品画面

五张Studio画面使用同一1440像素宽、浅色主题的真实Electron窗口，连接本机领域服务并打开《今晚，让春天亮起来》的独立副本。配音画面展示已保存的本地文本草稿；作者尚未发送生成请求。Player画面来自该作品实际Web发行物，在Microsoft Edge中运行。

| 图片 | 用途 |
|---|---|
| [演出](stage.png) | 场景树、指令卡片、当前指令舞台与属性 |
| [写作](writing.png) | 连续对白、说话者与同一场景上下文 |
| [页面](pages.png) | 组件树、作品页面画布与属性 |
| [配音](voice.png) | 文本、语言与本地制作草稿状态 |
| [发行](publishing.png) | Web/Windows目标、实际保存版本检查与构建入口 |
| [Player](player.png) | 实际独立Web Player中的剧情呈现 |

[工作区轮播](workspace-overview.gif)依次显示演出、写作、页面、配音和发行，停留5、4、4、5、4秒。轮播以真实静态截图直接切换，仅缩放并添加画面用途标注。静态PNG供读者放大查看。

Studio images show the real Electron client and local service. The voice screen contains a saved draft with no generation request sent. The Player image shows the actual Web release in Microsoft Edge. The 22-second GIF presents these screenshots with bilingual captions; the PNG files provide full-size alternatives.
