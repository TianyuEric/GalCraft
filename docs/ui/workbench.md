# 工作台交互

M01 分别管理 Workspace、Document、Selection 和 Inspector，预览持有自己的有效来源。领域模块提供实际编辑、保存及生命周期，工作台按这些投影组织交互。

## 布局与文档

顶部显示作品身份、命令搜索和全局动作；Activity 切换任务领域；Explorer 展示当前任务对象；中央文档承载正文、图、画布或详情；Inspector 展示当前对象；问题/搜索底栏只占中央列。正文、Explorer、Inspector 和长结果分别滚动，主要提交区持续可达。

900px 窗宽优先保障中央编辑区，辅助栏沿现有窄窗机制显示；窗口变窄、聚焦或临时无适用面板只改变展示。用户主动拖动和折叠写个人偏好，展开返回上次设定宽度。分隔条支持 pointer、`role=separator`、方向/当前值/范围，键盘每次 10px 调节，Home/End 到边界。关闭焦点所在区域后，焦点返回稳定入口。

聚焦模式保留编辑器、输入缓冲、选区与历史，退出恢复布局。未选对象时，Inspector 保持稳定区域并说明当前可执行动作。低频动作进入具名溢出，高频工具最多组织两行，正文保持可读字号。宽表格可在自身命名区域横向浏览。

单击对象使用预览标签，双击、Enter 或首次修改固定文档。同一身份跨工作区保持一个文档。预览替换先处理原草稿与未保存内容；切换和返回保留输入、光标、滚动、选区及所属历史。关闭标签只作用该身份，再激活相邻有效文档。

写作/演出/源码是同一文档的表达，视图切换先处理当前输入。无效源码保留原文、诊断与最近有效内容，其他视图按适用只读规则呈现。文档 Tabs 的活动标记、dirty、关闭和溢出始终可辨。

## 选区、树与对象菜单

| 概念 | 用途 |
|---|---|
| 完整选区 | 本次批量动作的稳定对象集合，可跨页或筛选保留 |
| 主对象 | 单对象详情及定位 |
| 键盘焦点 | 导航及 F2 等作用入口 |
| 范围锚点 | Shift 范围选择起点 |
| 活动文档 | 当前打开的工作对象 |

实现使用既有状态拥有者。点击行后焦点进入该行；树采用 roving focus，上下键移动可见行焦点并保留选区，左右键处理层级。场景 Enter 收敛选区、打开并固定聚焦场景；章节 Enter 展开/折叠。其他树按其领域激活约定处理。

Ctrl 点击切换集合，Shift 按当前显示顺序和锚点扩展。右键已选对象保留集合，右键未选对象将范围切到该项，空白处提供集合动作。菜单、工具栏、Inspector、确认标题及提交读取同一时点选区。隐藏选择继续计数并提供清除入口，筛选结果数与完整选择数分别说明。

对象使用稳定 ID，名称和排序位置负责展示。重命名保持行位置，输入本地处理 F2/Esc/Enter，IME 组合确认保持输入语义。素材重命名只编辑名称主体，原后缀单独显示并保留大小写；批量预览与提供方使用同一规则。

行内动作使用至少 28px 命中区的 ghost 按钮，名称、Tooltip、焦点和实际快捷键可读。对象右键、更多和工具栏使用同源命令、范围与可用性。危险项置末组，长菜单局部滚动。文本输入与 Monaco 保留自身编辑菜单。

## 命令搜索、键盘与 IME

命令搜索锚定顶部触发器，目标宽 560px，左右至少留 12px，间距 4px，高度适应可用空间，结果区独立滚动。缩窗、移动锚点或标题栏改变时重新定位。搜索为非模态浮层，保留作品上下文。

Ctrl+P 打开对象搜索，Ctrl+Shift+P 打开命令，Ctrl+F 留给当前编辑域；菜单、Tooltip、搜索和帮助读取实际命令注册值。输入/IME、弹层、局部编辑器及工作台按所属范围处理快捷键。组合期 Enter/Esc 保持输入语义，迟到搜索结果失效。

打开搜索保存来源焦点，上下选择结果、Enter 执行；禁用项显示原因。Esc 关闭后返回来源，来源已移除时返回触发器。外点关闭后保留本次点击的新目标焦点；执行跳转后由目标入口接管。无结果保留查询并提供清除或切换条件。

重命名、字段与自然语言编辑保留 IME、选择和剪贴板。对话框使用 Base UI 焦点管理，将焦点留在当前层，关闭回来源或当前文档稳定入口。短决定层退出后再进入持续保存审阅，前景保持一个可操作层。

## 编辑、拖动与预览

Inspector 顺序为对象/数量、常用内容、布局/外观、专项、高级详情。字段显示标签、单位、范围和就地错误；空值、负号等中间输入保留本地，合法确认才提交。多选显示共同字段及混合值，未触碰字段保持原值。锁定 Inspector 明确标明对象。

连续滑动或拖动只预览本次值，释放时一次提交，Esc 恢复开始值。确认等待所属事务结果，pending 约束重复提交，失败保留输入。Enter 确认后保留适用焦点，Esc 返回来源控件，外点确认保留新的焦点目标。

排序从实际握柄或受支持区域开始，文字区保留选字，按钮/输入处理自身事件。落点说明行前/后/末尾，边缘自动滚动；拖已选对象移动当前集合，拖未选对象只移动自身，保留相对顺序与稳定身份。完整排序一次 M02 事务和撤销。Esc、无效落点或离开有效范围取消并保留选区与焦点。单条 Alt+上下排序与整组跨场景移动各按实际入口提供。

文件投放与选择器复用 M04 导入、类型和版本规则。目标说明类型及插入/替换范围；取消或失败保留原内容。资源预览保持作品不变，成功绑定才更新最近使用。切换、关闭或迟到资源回执释放所属租约。

舞台显示当前语句、最近有效内容或暂无预览，并注明对象和版本来源。旧请求只能更新匹配上下文。静止 Inspector 展示转场末帧，Player 继续执行实际转场时序。页面草稿使用临时模板，动画/循环/颜色试听使用所属临时会话，确认才进入领域事务。

## 保存、错误与长内容

“应用”改变工作内容，“保存”写磁盘，“预览/试听/查看历史版本”保持正式内容。保存审阅使用 M02 实际对象、初选、必要关联和完整净差异，逐对象展示字段前后值与位置。取消保留 dirty，未选修改继续未保存。丢弃先审阅实际范围，确认立即生效并可撤销。详见[保存契约](../reference/editing-and-saving.md)。

危险操作说明对象、范围、后果和可撤销性，默认取消；Esc、遮罩、关闭和取消按同一业务规则处理。长影响、正文与代码局部滚动，底部动作持续可达。160 行代码分页及超长单段原文显示保留全文复制。

空库提供创建/导入主动作，无结果提供清除筛选，未选对象提供短说明，缺包/精确版本提供修复定位。错误持续显示具体原因及恢复动作，输入、有效旧结果和来源继续保留。全局错误在中央工具区下可见，Inspector 折叠后仍可处理。成功 Toast 只确认真实完成且保持焦点，状态仍留在所属页面。

## 持续工作与历史

长方案、连接、样式、模板选择和采用计划使用持续中央文档，保存/取消与来源可达。上下文资料采用清单加详情：勾选决定发送，名称打开全文，上下浏览，Enter 将焦点交给详情并提供返回原行。筛选保留选择及来源变化提示。

制作记录和草稿每页 20 项，候选每页 12 项，协作调用每页 25 项。多页时显示共享分页，翻页保留当前任务的选区和编辑；技术详情展开时再构建代码预览。离开制作/协作或隐藏窗口停止所属 renderer 轮询，重入读取最新状态，宿主任务及草稿沿原生命周期运行。

标题栏使用可收缩作品名视口和独立 dirty 标记，名称仅在实际溢出时慢速往返，hover/聚焦暂停，减弱动画静态显示。发布为主动作，本机服务位于同组次要入口；交互区与弹层使用 no-drag，空白标题栏保留拖窗。900px 时收紧搜索文字和辅助动作，服务与窗口操作保持可达。
