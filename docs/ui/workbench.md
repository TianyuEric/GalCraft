# 工作台交互

M01 分别管理 Workspace、Document、Selection 和 Inspector，预览持有自己的有效来源。领域模块提供实际编辑、保存及生命周期，工作台按这些投影组织交互。

## 布局与文档

顶部菜单提供作品、编辑、工作面、布局与帮助入口，并显示作品身份和命令搜索。左、右工具区各使用图标轨，底部使用工具按钮，每区显示一个活动工具。中央文档承载文稿、图、画布或详情。正文、工具、属性和长结果分别滚动，主要提交区持续可达。

侧栏同类工具可左右移动；底栏承载横向工具；中央文档支持分组和分屏。视图注册声明稳定身份、默认区域、允许区域、最小尺寸及生命周期。收起隐藏一栏，关闭移除单个工具，再开恢复其现场。移动、隐藏和临时收纳保留同一视图实例与编辑现场，关闭才执行所属输入保护和资源释放。

窗口变窄或局部最大化只改变展示，保留输入、选区、历史及原摆放。辅助工具可从收纳入口临时展开，空间恢复后还原；放不下的新分屏保留现状，并提供同组打开或局部最大化。用户主动调整写入作品现场，临时收纳不覆盖命名布局。分隔条支持 pointer、`role=separator`、方向、当前值和范围，以及键盘调整。关闭焦点所在区域后，焦点返回稳定入口。

单独打开工具只改变所属栏，切换中央对象只改变目标组及明确跟随的内容。「工作面」组合打开一项任务所需的对象和工具，沿用工具现有区域；同栏当前工具属于组合时保留，否则按组合顺序激活。有有效主对象时打开或复用其中央标签，无主对象时保持中央内容并聚焦主要工具。文稿与舞台、素材管理、角色差分及页面搭建分别提供组合。

命名布局是个人可跨作品复用的模板，以可解析槽位记录摆放；作品现场自动保存具体文档、视图及来源。作者显式应用模板，后续调整继续保存当前作品现场，使用更新动作才覆盖模板。首次打开没有现场的作品时展开剧情目录，并打开有效起始场景；重开接续仍打开的作品及可恢复现场。

剧情树单击预览，双击、Enter 或首次编辑保留文档；作品库单击详情、双击打开作品；素材库单击更新主选中与跟随属性，行名称、缩略图及空白双击统一打开中央预览，行内按钮和输入处理自身事件。预览动作及 Enter 继续可用，改名使用 F2、对象菜单或素材属性。同一素材复用 `asset:<id>` 文档，显式并排可打开同一文档的不同视图。替换预览和关闭标签先处理未应用输入；切换与返回保留光标、滚动、选区及所属历史，关闭后激活相邻有效文档。

写作/演出/源码是同一文档的表达，视图切换先处理当前输入。无效源码保留原文、诊断与最近有效内容，其他视图按适用只读规则呈现。文档 Tabs 的活动标记、dirty、关闭和溢出始终可辨。

从「工作面」或命令搜索打开「页面搭建」。每个页面是独立对象标签，画布、样式、行为和导航预览在页内切换。显式并排的画布与行为图共享页面身份和保存目标。工作台提供文档标题、保存与历史。「显示工具」切换页面目录与大纲，「页面操作」打开模板、动画和启动相关工具。每页恢复自己的模式、选区及画布位置，页面大纲跟随最近激活的中央页面。独立页面编辑器保留本地保存与历史。

管理任务从完整工作面及命令搜索直达。剧情目录把常用树操作留给当前对象，角色目录、关系图和作品设置收进「更多入口」。布局菜单按栏位显隐、独立工具和命名布局呈现，Dock 提供底栏名称及问题计数。

从组件的属性来源打开已有命名样式时，工作台复用该样式的中央标签、作用范围和草稿。编译及应用使用所属样式身份，作者从工作台审阅保存。开屏片段的未应用时长、颜色和所选片段随保留输入恢复；确认放弃后，重开读取已保存内容。

## 人物资料与引用

角色目录、对白说话人、立绘指令及属性中的「编辑〈人物名〉」按稳定人物 ID 打开或复用 `character:<id>` 文档。引用入口记录实际来源场景、语句、视图、选区、光标、滚动及焦点；固定对象属性使用其固定来源。作者选择「返回原句」后恢复该上下文，键盘进入时返回原入口焦点。来源版本或语句失效时保留人物文档与输入，并说明原因。

「资料」优先呈现简介与创作设定、外观说明及参考图，默认演出独立收纳；共同差分、头像与声音、路线与结局保留所属入口。正文独立滚动，当前人物保存和「仅应用到工作区」持续可达。人物被剧情引用时继续允许编辑资料，删除沿引用检查处理。

人设参考图和共同差分从各自字段打开同一素材选择器，沿字段的类型、当前引用及版本规则查询和导入。参考图仅在明确应用后追加并去重，取消保留原列表及人物文本。共同差分保留 `variantId=null` 的浮动引用与精确 `variantId`，版本选择和预览继续读取对应版本。选择器将明确应用的选择交回原字段，人物工作修改继续经原编辑事务提交。空图片库也可从添加差分打开 Picker，导入后明确应用才创建差分，取消保留原人物输入。

旧全角色文档和聚合输入按稳定人物 ID 承接到单人物标签，各人物保留草稿、原依据及视图状态。已有作品人物按各自原依据三方比较后，经原编辑事务应用；其他人物保存推进作品版本后，独立未应用输入仍回到原人物表单。其他失效来源的输入继续留在恢复页。原人物尚未创建且草稿没有原依据时，先只读展示；作者明确选择「继续恢复此人物草稿」后才编辑，并经应用或当前保存创建同一 ID 的人物。保留关闭后从角色目录重开继续使用该 ID 和输入。有原依据但人物已删除时，保留输入与可复制详情，恢复原人物后继续编辑。无选中人物的空旧现场打开角色目录；旧聚合文档完成承接后退出现场。打开恢复入口本身保持作品内容与磁盘不变。

## 选区、树与对象菜单

| 概念 | 用途 |
|---|---|
| 完整选区 | 本次批量动作的稳定对象集合，可跨页或筛选保留 |
| 主对象 | 单对象详情及定位 |
| 键盘焦点 | 导航及 F2 等作用入口 |
| 范围锚点 | Shift 范围选择起点 |
| 活动文档 | 当前打开的工作对象 |

实现使用既有状态拥有者。点击行后焦点进入该行；树采用 roving focus，上下键移动可见行焦点并保留选区，左右键处理层级。场景 Enter 收敛选区、打开并固定聚焦场景；章节 Enter 展开/折叠。其他树按其领域激活约定处理。

Ctrl 点击切换集合，Shift 按当前显示顺序和锚点扩展。右键已选对象保留集合，右键未选对象将范围切到该项，空白处提供集合动作。菜单、工具栏、Inspector、确认标题及提交读取同一时点选区。隐藏选择继续计数并提供清除入口，筛选结果数与完整选择数分别说明。

对象使用稳定 ID，名称和排序位置负责展示。重命名保持行位置，输入本地处理 F2/Esc/Enter，IME 组合确认保持输入语义。素材重命名只编辑名称主体，原后缀单独显示并保留大小写；批量预览与提供方使用同一规则。

行内动作使用至少 28px 命中区的 ghost 按钮，名称、Tooltip、焦点和实际快捷键可读。对象右键、更多和工具栏使用同源命令、范围与可用性。危险项置末组，长菜单局部滚动。文本输入与 Monaco 保留自身编辑菜单。

## 素材浏览与本批返回

素材库将查询、排序、计数与导入保持同级可达，回执历史、失败明细及批量动作按需展开。底栏高度有限时使用完整紧凑行，较大浏览空间沿用卡片和类型预览。「聚焦浏览/还原浏览」复用所属 Dock 的局部最大化与还原，保留中央场景、未应用输入和原工具摆放，命名布局继续由作者明确应用。

「查看本批」仅以 M04 该批累计成功素材 ID 建立临时浏览范围，范围内查询继续使用 M04 的类型、目录、搜索和排序规则。进入前保留原查询、类型/目录、排序、页码、跨页勾选及范围锚点、主对象、所看版本、固定属性、滚动和焦点；「返回素材浏览」恢复该现场。个人现场持久化保留原浏览，临时范围保持独立。原批重试新增的成功 ID 加入本批浏览范围，既有勾选保持原集合；迟到的完整 ID 查询只更新仍匹配的范围。

查看、返回、聚焦和预览分别只改变浏览状态；导入、原批重试、字段应用与保存使用各自明确动作。导入结果同时显示累计成功和剩余失败，重试仅处理原批未导入项。原始 Issue 和每次尝试留在回执历史，全部恢复后问题摘要消失，已完成批次在重开后仍可从回执历史查看。

## 命令搜索、键盘与 IME

命令搜索锚定顶部触发器，目标宽 560px，左右至少留 12px，间距 4px，高度适应可用空间，结果区独立滚动。缩窗、移动锚点或标题栏改变时重新定位。搜索为非模态浮层，保留作品上下文。

Ctrl+P 打开对象搜索，Ctrl+Shift+P 打开命令，Ctrl+F 留给当前编辑域；菜单、Tooltip、搜索和帮助读取实际命令注册值。输入/IME、弹层、局部编辑器及工作台按所属范围处理快捷键。组合期 Enter/Esc 保持输入语义，迟到搜索结果失效。

打开搜索保存来源焦点，上下选择结果、Enter 执行；禁用项显示原因。Esc 关闭后返回来源，来源已移除时返回触发器。外点关闭后保留本次点击的新目标焦点；执行跳转后由目标入口接管。无结果保留查询并提供清除或切换条件。

重命名、字段与自然语言编辑保留 IME、选择和剪贴板。对话框使用 Base UI 焦点管理，将焦点留在当前层，关闭回来源或当前文档稳定入口。短决定层退出后再进入持续保存审阅，前景保持一个可操作层。

## 编辑、拖动与预览

Inspector 顺序为对象/数量、常用内容、布局/外观、专项、高级详情。字段显示标签、单位、范围和就地错误；空值、负号等中间输入保留本地，合法确认才提交。多选显示共同字段及混合值，未触碰字段保持原值。锁定 Inspector 明确标明对象。

连续滑动或拖动只预览本次值，释放时一次提交，Esc 恢复开始值。确认等待所属事务结果，pending 约束重复提交，失败保留输入。Enter 确认后保留适用焦点，Esc 返回来源控件，外点确认保留新的焦点目标。

排序从实际握柄或受支持区域开始，文字区保留选字，按钮/输入处理自身事件。落点说明行前/后/末尾，边缘自动滚动；拖已选对象移动当前集合，拖未选对象只移动自身，保留相对顺序与稳定身份。完整排序一次 M02 事务和撤销。Esc、无效落点或离开有效范围取消并保留选区与焦点。单条 Alt+上下排序与整组跨场景移动各按实际入口提供。

文件投放与选择器复用 M04 导入、类型和版本规则。目标说明类型及插入/替换范围；取消或失败保留原内容。资源预览保持作品不变，成功绑定才更新最近使用。切换、关闭或迟到资源回执释放所属租约。

素材选择器在已有结果中提供同级导入入口，沿用 M04 原导入回执。作者可查看本次成功素材形成的临时浏览范围，并返回原查询、tab、页码、选择、精确引用及滚动；失败回执继续可见。导入和查看成功项保持原字段及素材库勾选，选择后仍须明确应用，由原字段的 `onApply` 提交。取消或失败保留原绑定与选择。页面背景、组件图片槽及其他素材字段以稳定字段身份恢复焦点，字段文案或素材名称改变后仍返回同一字段，当前素材说明独立呈现。

舞台显示当前语句、最近有效内容或暂无预览，并注明对象和版本来源。旧请求只能更新匹配上下文。静止 Inspector 展示转场末帧，Player 继续执行实际转场时序。页面草稿使用临时模板，动画/循环/颜色试听使用所属临时会话，确认才进入领域事务。

属性和舞台分别跟随当前对象与剧情位置，固定操作绑定来源身份，固定后继续编辑该来源；浏览其他内容保持固定目标。界面持续显示来源与固定状态，失效时说明原因并提供恢复跟随。定位检查、从此句预览和连续试玩使用同一舞台入口，分别标明静态状态、局部运行与连续执行的来源。

## 保存、错误与长内容

“应用”改变工作内容，“保存”写磁盘，“预览/试听/查看历史版本”保持正式内容。保存审阅使用 M02 实际对象、初选、必要关联和完整净差异，逐对象展示字段前后值与位置。取消保留 dirty，未选修改继续未保存。丢弃先审阅实际范围，确认立即生效并可撤销。详见[保存契约](../reference/editing-and-saving.md)。

当前保存先确定本次目标，再校验并应用该目标的输入，然后进入 M02 保存计划、审阅及写盘。人物主按钮、Ctrl+S、菜单和关闭文档时的保存使用同一目标规则，显式指定的关闭目标及固定属性来源保持其身份。其他人物的未应用输入、未发送制作和无关发行草稿保持原状，当前保存可继续；目标自身无效、IME 尚在组合或字段冲突时保留输入并停止。人物「仅应用到工作区」只产生可撤销工作修改；应用后取消保存审阅仍保持未保存，可按该人物撤销。保存全部继续使用既有跨对象输入保护和审阅，制作发送、候选采用及复杂影响继续使用各自具名操作。

作品设置的语言、主角姓名与启动/主页的普通数值、序列数值在当前保存时先校验并应用有效输入。关闭保存保留本次逻辑视图身份；作品设置与启动/主页共用 M02 文档时，仍处理明确关闭的入口输入。非法姓名或数值保留原字段输入与焦点；真实事务期间沿所属忙碌约束。启动颜色和音频循环等复杂编辑继续使用原明确确认，当前保存保留其未确认状态。删除启动片段仅在原事务成功后清除该片段输入，失败或其他片段输入继续保留。无玩家视角人物时，设置入口引导打开角色目录及原人物资料。

危险操作说明对象、范围、后果和可撤销性，默认取消；Esc、遮罩、关闭和取消按同一业务规则处理。长影响、正文与代码局部滚动，底部动作持续可达。160 行代码分页及超长单段原文显示保留全文复制。

空库提供创建/导入主动作，无结果提供清除筛选，未选对象提供短说明，缺包/精确版本提供修复定位。字段错误在所属字段说明；操作结果使用浮层 Message，输入、有效旧结果和来源继续保留。关闭 Message 只结束提醒，所属诊断和恢复入口继续存在。撤销/重做、保存和本机去背模型准备失败保持当前底栏开合和编辑区尺寸，作者可从 Message 的「查看问题」或底栏入口打开诊断。

## 问题与恢复

「问题」是独立底栏工具，按当前作品汇总仍需处理的错误和警告；Message 提供本次短反馈，「输出」保留执行结果和产物入口，所属工作面持有输入、完整失败明细及实际恢复操作。工具入口与 Dock 标题显示待处理条目总数，搜索和严重程度筛选保留该总数；一个批次或任务的摘要计为一条。列表按文档、对象或任务分组，错误优先，每行提供短原因、来源、一个主恢复动作及按需展开的诊断详情。定位后返回保留选中、查询、筛选和滚动。

| 来源 | 问题及恢复入口 | 更新依据 |
|---|---|---|
| 编译、无效指令、缺素材和引用 | 逐条内容诊断，定位原文档、语句或字段 | 有效编译更新对应内容；编译未完成保留上次结果并标明状态 |
| 作品读取、精确引擎和依赖 | 读取原因、对象及作品维护/补齐入口 | 所属读取或健康检查确认恢复 |
| 保存 | 本次文档、对象集合或全部范围的失败摘要，「查看保存来源」返回原文档 | 成功保存对应范围，或重试确认该范围与 saved 一致后清除；无关保存和编译保留该失败 |
| 发布检查 | 内容及依赖诊断，定位所属工作面 | 输入变化标明需要重新检查；新有效检查替换，失败保留旧结果及未完成状态 |
| 构建 | 目标及本次构建失败，「查看构建回执」打开原 planId 的结果 | 同目标成功构建后移除失败；查看原回执保留当前发布目标和草稿 |
| 素材导入 | 按批次汇总「本批 N 项未导入」，「查看导入结果」打开原批次 | 原批次只重试未导入项，累计成功结果保留，剩余失败更新，全部恢复后摘要消失 |
| 制作 | 按任务汇总未完成失败项；请求或结果读取失败返回原草稿、任务或制作回执 | M10 的最新任务修订与请求状态更新；原任务继续承担查询、取回、重试及发送语义 |
| 连接与工作流配置 | 「查看连接与工作流」返回原配置及原始失败原因 | 保留未保存名称、模型族及待导入原文；返回只恢复来源，保存配置和发送请求继续使用各自操作 |
| 撤销/重做、本机去背模型准备 | 操作失败及原来源/本机工具入口 | 所属后续操作确认恢复 |

各来源分别替换自己的结果，同一任务的较新状态优先于迟到回执。检查或来源读取失败显示检查未完成并保留带状态的旧结果；导入和制作的旧摘要标明需要重新检查，恢复读取后更新该来源。「当前没有问题」只表达有效的空结果。普通取消保留在所属执行结果。无精确定位时，主动作打开所属工作面并说明范围；来源失效时保留诊断及原因。所属工作面使用一份原始 Issue 说明失败，技术详情按需展开。

操作失败提供「忽略本次」，只把该次失败摘要移出待处理列表，原回执、任务失败状态和成功结果继续保留。「已忽略」可查看这些条目并「重新关注」。M01 按作品在个人工作区保存最小尝试身份，重开继续尊重该选择；新尝试失败重新进入待处理列表。内容诊断随检查显示。关闭 Message、收起底栏或清理输出只改变所属表面。

「重新检查」复用作品读取、编译、引擎健康和已有发布检查，并读取现有导入、制作状态；该动作可在作品只读时使用，保持保存、导入、生成、采用和构建各自的明确启动入口。后台刷新使用同样的读取边界。作者主动检查或构建被错误阻断时展开问题并保留键盘焦点；普通操作和后台失败只更新计数并提供 Message 入口。

「输出」保留最近保存和最近成功构建的实际回执，失败和取消使用独立状态，原成功产物入口继续可用。只读原因及「作品维护」入口持续显示在状态栏；从诊断定位后的「返回问题」「返回发布检查」和素材来源返回动作位于当前场景工具栏，其他文档使用状态栏。切换文档保持诊断的原始来源。
