# Player 设计

Player 让玩家连续阅读、调整节奏、保存位置并返回原处。舞台和台词优先，辅助动作在需要时出现。同一作品画布贯穿设计、阅读、系统页与发行；M08 模板提供作品色彩、字体和组件语义源。

## 画布、层级与输入

所有尺寸使用作品设计像素，整个逻辑画布只缩放一次。标准 1920×1080 下，正文 26/39px、菜单 24px、辅助 20px，字重使用 400/500/600，文字使用 primary/secondary/tertiary/muted 层次。作品字体优先，CJK 按正文语言回退；阅读字号只影响剧情、历史和样例正文。

间距以 4px 为基础，同组 8px、组间 24px、页内 48px。普通按钮至少 120×48px，剧情工具栏文字动作至少 96×48px并随文字增宽，图标动作至少 48×48px；标题区 72px、页脚 64px。作品配置覆盖公开值。长按钮标签自然换行并保留内边距，图标和文字按真实内容居中。

表面、边框、圆角、阴影和状态前景/背景由同一作品模板提供。确认层保留来源舞台并增加暗罩。Web 窄屏完整缩小画布，布局仍由逻辑尺寸确定，黑边保持独立于游戏输入。纯展示文字禁选、图片禁止原生拖动；真实编辑区保留 IME、选择和剪贴板。

所有动作具备 hover、pressed、focus、disabled，异步内容具备 loading、empty、error、success。模态焦点进入并留在当前层，关闭返回来源，来源控件消失时返回当前页根；错误保留可恢复现场。

## 阅读与系统页

| 模式 | 当前规则 |
|---|---|
| 剧情工具栏 | 存/读/快存/快读、历史/设置、自动/快进三组；固定和语音重播为具名图标，低频动作进更多。鼠标通道和内部焦点保持可见，显隐保持阅读区横向几何 |
| 设置 | 左侧阅读显示、右侧声音常用总览，详细分类承接其余字段；稳定区域显示实际阅读预览，显式试听一次一个声源 |
| 确认 | 正文、可选偏好、横向确认/取消依次排列，长正文局部滚动，来源舞台保持 |
| 历史 | 台词优先，试听使用独立具名图标，回跳使用独立文字按钮，技术身份进入详情 |
| 存/读档 | 详情 30%、槽区 70%，4×3 固定网格；槽号、固定图片区、单行摘要和独立时间行，空满/加载同尺寸；单击选择，双击或主按钮执行 |
| 剧情选项 | 行随正文和原因增高，单行至少 84 设计像素，文字和内边距完整位于按钮内；长列表在所属区域滚动 |
| 后日谈 | 横排角色卡，默认上半身取景，窄画布横向浏览；解锁后整卡每次从头进入，读档显式恢复中段 |
| 锁定后日谈 | 同一卡片显示均匀剪影，隐藏当前角色的姓名、简介、剧情与动作，保持不可激活语义 |
| 鉴赏 | 主区与音乐侧栏约 2:1，音乐列表独立滚动，音量、进度与播放分组；长标题保持在卡片内 |

存档 selected 优先于 hover，normal/hover/selected 使用可读的成对色。后日谈临时 selected 表示点击至进入的过渡。角色裁切在 Studio 支持拖动、键盘等价操作及 Esc 取消，完成手势才经 M02 提交。

普通 UI 动画使用具名预设，时间约 120–220ms；工具栏按真实方向和隐藏边界运动。退出结束再移除，反向从当前呈现值接续。减弱动画采用 finish/fade，保留可辨状态。

## 共享选择、文字与编辑覆盖

设置、语言、流程图、作者 `basic.select` 和资料导入共用 PlayerSelect。触发框、列表、选项继承作品字体和语义令牌，通过公开 normal/states 接受作者样式。Portal 位于同一逻辑画布，定位换算一次。默认触发最小高 48、选项 44、列表内边距 4、选项内边距 6×12，均为设计像素；长列表滚到活动项。

PlayerSelect 支持鼠标、方向键、Home/End、文字检索、Enter 和 Escape，保持真实业务值与返回焦点。显示文字覆盖限定于选中部件和 Player 菜单语言；恢复默认删除该语言覆盖。Studio 语言只影响编辑面板，动态角色、存档和剧情继续使用所属绑定。

M08 公开组件、M07 动作和正式 Storybook 提供共享实现。Studio 设计模式的视觉 Player 样例从朗读树隐藏，内部焦点交回设计画布；组件树和 Inspector 承担编辑。导航预览保持真实 Player 交互，作品样式与 Studio 主题各在自身作用域生效。

新公共模式先进入正式 Storybook，再由实际页面复用。浏览器观察比例、焦点与输入，真实 Windows 观察客户区及磁盘，独立目标观察发行运行。产品行为及平台范围见[运行与发行](../reference/runtime-and-publishing.md)。
