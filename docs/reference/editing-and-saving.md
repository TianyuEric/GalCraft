# 编辑、保存与恢复

M02 唯一持有作品的 working、saved、操作日志、关联组、恢复草稿和磁盘事务。M01 维护工作台输入、选区和表现，M04 通过 M02 提交素材索引。每个作品由一个写会话管理，重复打开返回已有会话；外部修改进入磁盘冲突处理。

## 编辑与历史

作者操作和外部协作共用 `planEdit`、`applyEdit`。提供方在计划中记录 expected 版本、before 内容、补丁、成员及必要引用；应用时先在副本检查全部修改和引用，成功后一次替换成员并登记操作。失败保留原工作内容。JSON 数组重排记录完整前后值，DSL 使用源区间补丁。

工作台的写作、演出和源码视图共用语句身份、选择和 M02 历史。手工源码可以暂时无效；M01 保留原文、诊断与最近有效视图，M03 继续检查语义。生成候选、模板和预设在接受前通过所属语义检查。

输入控件保留空值、负号、未闭合文本等中间输入。字段在所属确认边界提交，IME 组合期间继续本地输入。连续拖动和滑杆使用临时预览，释放时提交一次，Esc 恢复起始值。控件本地 undo 先处理未提交输入；已提交编辑由 M02 历史处理，同一变更登记一次。

M01 提供当前文档及适用字段范围，M02 查找该范围最近操作，并按实际补丁相交及关联依赖扩展撤销闭包。确认前显示跨文档成员和后续依赖；撤销按操作逆序应用，重做按正序应用。新编辑使实际相交的重做分支失效，独立字段保留原分支。排序、批量粘贴和候选采用按原关联组撤销。

恢复草稿保留工作内容和必要关联；完整撤销历史属于当前打开会话。恢复后，作者通过新的工作版本继续编辑和保存。

## 对象保存与丢弃

保存单位是逻辑作者对象：场景的 `scene.json` 与 `script.gal` 合为一个对象，单角色、项目设置和其他作者文档各自成对象，素材索引按稳定 `assetId` 分对象。同对象字段一起保存，字段差异用于审阅。

`current` 以当前文档 dirty 对象为初选，`all` 以全部 dirty 对象为初选，`objects` 使用明确对象集合及 expected。M02 计算实际闭包及逐项原因：必要引用和不可拆分关联编辑联动，共享物理文件本身保持各对象范围。取消必需依赖时，M01 同步撤去依赖它的选择，并取得新计划。空选择保持空范围。

保存计划冻结版本、内容和实际对象集合。M02 在 saved 上仅合入所选对象的净变化；素材索引只合入选中 `assetId`。开始写盘前版本变化要求重新计划。成功后，M02 更新实际落盘 saved，再按完整 working 重算 dirty；未选对象和事务期间产生的更晚编辑继续未保存。备份与正式构建读取 saved。

“丢弃此项修改”或“丢弃已选择”先由 M02 规划实际对象闭包，说明引用和恢复关联。普通文档按整对象、素材按 `assetId` 计算范围；同一次批量编辑本身保持各对象可独立选择。作者确认后立即改变 working，登记一次可撤销操作，磁盘 saved 保持。取消审阅保留实际内容及选择；已执行的丢弃继续有效，作者可使用撤销恢复。

部分保存后，离开保护继续处理剩余 dirty。关闭作品、切换作品或退出时，作者继续保存、明确丢弃或取消；保存后出现新编辑时再次处理实际集合。

## 磁盘事务与冲突

M02 使用带旧文件副本的文件组事务：

1. 提供方比较本次成员的磁盘文本与基线；发现外部变化时先返回冲突。
2. 提供方在作品 `.galcraft/transactions/` 准备完整 new/old 及 `prepared` 记录，M04 不可变资源先准备到位。
3. 提供方记录 `installing`，以同目录临时文件逐项替换目标；全部完成后记录 `committed`，关闭句柄并返回整组回执。
4. 安装失败时，提供方恢复完整旧组并保留 working。仍有文件占用时，提供方保留 old/new 与事务，显示恢复待完成；作者释放占用后重试。
5. 启动时，提供方保留 committed 新组，对 prepared/installing/rollingBack 恢复旧组。清理失败保留成功保存结论并提示具体占用。

准备完成前可取消；进入安装后，提供方完成提交或回滚，再报告真实结果。事务期间，应用的打开、备份与构建等待完整磁盘组；内存编辑继续。普通外部程序可能在短安装窗口观察到文件先后更新。

监听事件提示可能变化，提供方读取比较后再处理。未修改内容可重新加载；dirty 内容保留 base/local/disk 三份。审阅提供保留工作内容、使用磁盘内容或另存副本，默认选择另存副本。提交时冻结处理方式与路径；磁盘再次变化时更新比较并重新确认。使用磁盘版本只替换冲突路径，保留工作内容继续 dirty，失败与取消保留可继续处理的入口。

M02 在已提交编辑停顿 1 秒后更新恢复草稿，连续编辑最长 10 秒更新一次。写入使用临时文件替换，失败保留上次草稿并显示恢复未更新。M01 另由所属个人恢复状态保存实际未应用字段，恢复后仍经所属编辑事务应用。

## 创建、备份与恢复

创建作品时，M11 提供精确引擎，M08 生成模板独立副本，M02 分配新作品及内容身份。提供方先在空临时目录准备完整内容，成功提交目录后登记最近作品。打开先恢复磁盘事务，再读取作品与依赖，最后处理恢复草稿。

备份收集已保存作品、所需资源与精确依赖信息。恢复先检查包、目标目录及依赖，再准备完整目录；“创建独立副本”分配新作品身份，原备份继续可用。缺包保留明确诊断，作者补齐所需精确版本后继续。目录操作在成功移动后才更新路径或注销会话；失败保留原目录及可恢复状态。

产品操作见[作品与文件](https://galcraft.dev/docs/zh-CN/projects-and-files/)。实现入口为 `packages/documents/`，对象保存由该包的 scope、计划和事务共同定义。
