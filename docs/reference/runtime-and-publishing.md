# 运行、资料与发行

M03 编译和检查，M05 执行剧情，M06 执行演出，M07 管阅读交互与玩家资料，M08 管页面/样式，M11 管引擎与发行。Studio 试玩、候选预览和独立 Player 复用实际运行能力，各自使用所属资料域。

## 作品内容与运行状态

章节顺序组织导航；作品 entry、语句和控制流决定执行顺序。写作、演出及源码共用正式 DSL 和指令目录，插件字段通过所属公开定义接入。手工源码保存原文，语义错误由编译与发行检查定位。

M05 管当前执行帧、变量、分支、等待和恢复；M06 管舞台对象、媒体、动画实例及其时钟。语句、角色、对象、素材和版本分别使用稳定身份。对象动画针对实际对象，持续动画使用作者实例引用，停止只处理该实例仍拥有的字段。对象退场清理自身实例，存读档按真实快照恢复演出，恢复保持原过程而非重新发送生成或平台动作。

M07 持有页面来源栈、焦点、阅读策略、存档、继续点、历史与个人偏好。菜单、弹层和辅助页面记录 home/stage 来源；设置、历史和存档关闭后回到原位置。试听一次只占用所属声源，返回按来源恢复背景。页面、窗口失焦和回避分别形成暂停原因，由实际时钟处理。

玩家存档保存剧情及演出进度，长期资料保存已解锁事实，偏好单独持久化。读档恢复目标进度，保留已经成立的长期事实。正式玩家、Studio 试玩及候选使用各自域；候选预览保持正式长期资料和真实平台成就。读档先准备和校验完整恢复内容，成功后原子发布新会话；失败保留原可用状态与修复入口。

作品配置分别维护菜单支持/默认语言、正文源语言、配音支持/默认语言。M08/Player 能力决定菜单候选；菜单与配音偏好分别保存，单语言域隐藏选择，空配音域隐藏默认项。正文继续使用作者原文，TTS 优先采用独立朗读文本；稳定语句 ID 与配音 locale 匹配音频。

普通后日谈属于已交付作品能力，角色展示配置归 M02、公共卡片外观归 M08。进入后日谈每次从头开始，明确读档恢复中段；临时回想与后日谈保持持久正篇来源。AI 后日谈属于 Backlog。作品姓名配置与玩家个人姓名按各自作用域保存，具体 schema 由 `packages/contracts/` 及 Player 资料实现维护。

## 素材、预览与模板

M04 使用稳定素材 ID 与不可变版本。消费契约决定跟随当前版本或固定版本；预览租约使用明确解析版本。专属类型目录向 Explorer、选择器、Inspector、候选和预览提供相同类型身份。缺类型包或精确版本时，系统保留原数据和引用，显示受影响能力。

Studio 的舞台、模板、素材和候选预览使用实际 Player/所属提供方，带有可读对象及版本来源。迟到回执只能更新仍匹配的请求；最近有效画面显示自身来源。预览和试听保持作品工作内容，采用和字段确认才进入编辑事务。

M08 维护作品逻辑画布、组件、菜单文字与样式源。作品画布整体缩放一次，Studio 设计器只增加编辑覆盖。作者 CSS 沿公开属性优先级覆盖，并保留属性来源说明。设计模式将交互焦点交给编辑画布；导航预览保留真实 Player 交互。

## 引擎与发行计划

M11 按作品 Lock 选择精确引擎。安装引擎只增加本机可用版本；作品切换使用明确转换计划、原件备份与作者确认。转换在副本检查 DSL、页面/样式、资源、插件状态及代表旧档；缺转换路径时保留原版本并说明限制。版本字符串变更由实际转换结果支撑。

M11 从已保存快照构建，检查引擎、插件、素材、页面和目标能力，冻结目标及选项。更改影响构建的设置后重新检查生成当前计划。筛选问题列表保留全部实际阻塞。诊断按 error/warning/info 表达严重度，技术代码进入详情；warning/info 直接显示具体情况。

目标构建器消费冻结计划和暂存目录，M11 管进度、取消及最终目录提交。构建或取消失败保留旧发行物。运行包携带实际所需的 DSL 执行产物、Pixi、模板、精确插件及资源；Studio 的编辑器、个人任务库和生成环境保持在创作端。发布前的资源验证、保存快照与 M11 准入各由所属提供方判断。

## 平台范围

| 项目 | 当前能力与前置 | 声明边界 |
|---|---|---|
| Studio | Windows x64 首发；桌面与本机浏览器共用服务 | 其他打包目标由构建工具提供选项，实际支持随发行验证扩展 |
| Web Player | 独立浏览器发行；资源使用发行清单 URL | 浏览器能力、媒体自动播放与目标插件按实际运行环境处理 |
| Windows Player | 独立 Electron 发行与 Windows 资源/资料宿主 | 原生插件按精确目标和架构提供真实运行依赖 |
| Android | 工程、APK、AAB；APK/AAB 使用实际 JDK、Android SDK、Gradle 及签名 | 工程导出可独立进行；产物构建、签名和真实设备运行分别检查 |
| iOS | 导出 Xcode 工程；macOS 入口调用 Xcode 构建/签名 | 归档、Apple 签名及真机需要作者的 macOS、账号与设备环境 |
| Steam | Windows 精确插件装载生产 SDK 和原生文件 | 试玩使用模拟；实际账号解锁由真实平台结果支撑，Web 可选能力按声明跳过 |

Android 环境准备先检查已有工具，再让作者选目录或下载位置并确认 SDK 许可。工具装在所选位置的自身子目录，保留其他文件。取消保留成功组件。可分享工程清除个人工具路径、签名路径与密钥；AAB 默认使用作者发布签名，本地测试签名需明确选择。无发布身份时作者可导出工程。

当前本地产品检查覆盖调试签名 APK/AAB 产包及 Windows 上的完整 Xcode 工程导出。Android 设备安装/运行、作者发布签名、macOS 归档、Apple 签名和 iOS 真机运行需要对应环境，发布者按实际检查说明范围。

移动目标是薄原生宿主加 WebView，复用剧情、模板和资源；输入、安全区、返回、前后台及资料提交经 `PlayerHost`。移动工具下载、发行构建与 M10 生成计数分别记录。构建成功说明相应产物已生成，设备支持结论使用实际平台观察。

## 版本边界

Studio 应用版本由 `apps/studio/package.json` 维护，生成的桌面/npm metadata、产物名、MCP initialize 与网站标签使用该实际应用版本。自有发布组件当前统一 `0.1.0`；作品发行号、数据 schema、存档及贡献契约继续使用各自版本。

作品与存档的可读范围、已测插件组合及显式转换入口随发行说明维护。升级前保留作品与个人数据备份；回退应用和恢复数据分别操作。已对外发布的同名同版本保持内容一致，历史精确依赖用于对应作品恢复。打包和签名步骤见[发行](../releasing.md)。
