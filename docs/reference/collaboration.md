# 外部创作协作

M12 将外部 MCP 调用转成有明确作品、范围、业务身份及可查询结果的创作动作。宿主管监听与协议适配，M12 管个人会话、范围和回执，实际模块持有作品、素材、任务与发行状态。Studio 界面和外部助手消费同一业务接口。

## 接入、作品与范围

本机服务、MCP 启用和协作暂停分别控制。MCP 首次默认关闭，用户明确启用后保存设置。Studio 展示实际端点与客户端配置；用户可以复制、导出或明确合并 GalCraft 配置项，原有其他服务和设置继续保留。客户端的工作目录、项目可信、权限与模型由客户端自身管理。

助手通过项目控制入口发现、创建或打开作品，再显式准备并应用当前作品协作。普通读取保持读取语义。每次业务调用携带明确作品和当前协作身份，提交同时检查工作版本。

新作品默认范围覆盖当前作品实际可用能力，`maxGenerations: null` 表示未设额外生成次数上限；实际发送持续累计。作者可以限定对象、操作、工具、连接、模型与工作流。M12 校验会话和工具，M02/M04/M10 等提供方校验完整事务及实际参数。采用同时满足编辑与采用范围。

同一作品在个人工作台维护一轮未结束协作，多客户端共用活动轮次。M12 串行登记受理与发送，M02 按版本处理并行编辑。切页、断连、暂停、重绑和同轮目标调整保留范围、暂停值、实耗和额外上限；新一轮沿用作品个人范围设置并从零计数。

## 调用身份与回执

修改、导入、制作和采用携带稳定外部调用标识，其作用域为协作会话。M12 在分发前保存工具、参数、目标、范围引用和版本，提供方关联真实业务结果。

| 请求情况 | 处理规则 |
|---|---|
| 同一调用标识、相同业务输入 | 返回原受理状态、业务身份或结果 |
| 同一调用标识、不同业务输入 | 返回标识冲突，调用者使用新标识表达新动作 |
| 普通读取和状态查询 | 返回当前内容、版本与状态 |
| 响应丢失或客户端超时 | 按原标识核实已受理业务，继续使用原编辑、素材、任务或采用身份 |
| 提供方尚无法确认结果 | 返回待核实及可查询信息 |
| 作者明确重做 | 使用新调用标识，按所属规则生成新计划或新请求 |

短事务返回实际结果；长任务完成受理后即返回调用标识、业务 ID 和状态，助手通过状态/结果/取消工具继续。结果包含可读摘要、结构化回执和 Studio 定位引用，大媒体沿资源引用读取。协作回执汇总提供方结果，业务持久记录负责恢复真实提交事实。

M10 采用跨越素材准备与作品编辑。提供方在应用前保存采用意图，M02 接受后确认 M04 文件并补齐同一采用记录；重启核实原回执完成未写完的关联。查询采用结果时先执行这项补齐。

## 暂停、取消与断连

暂停阻止后续作品修改、采用和新增生成发送，读取、状态查询及已发送结果取回继续可用。M10 在实际发送时再次检查当前范围、暂停和额度，排队但未发送项同样受约束。恢复先核对当前会话、依赖、范围及对象版本。

| 动作 | 结果 |
|---|---|
| 离开协作页面或断连 | 已受理业务按提供方生命周期继续 |
| 缩小范围 | 后续动作及未发送项按当前范围检查，已完成内容继续保留 |
| 已发送远端任务 | 按原远端身份查询和取回到原任务 |
| 明确取消 | 通过所属业务端口执行，分别报告本地与远端实际结果 |
| 已应用编辑或采用 | 保留 working，作者使用 M02 撤销或继续编辑 |
| 旧写会话失效 | 历史查询核实原结果，新写入使用当前有效绑定 |

原任务恢复读取使用原项目、会话、调用或任务身份核实请求，保持原配置、attempt 和发送计数。未发送后继等待作者明确继续；同作品当前有效协作可显式接手，提供方检查未发送项的真实操作、连接、模型、工作流及额度，再持久化新的后续执行授权。原来源身份与冻结输入继续保留。

结束轮次或删除已结束详情保持所属业务：M02 事务、M10 任务、候选、冻结输入及必要发送事实继续由原模块保存。M12 删除该轮个人目标、参数与结果日志，保留恢复所需的最小身份和结束事实。结束后的前身维持历史身份。

## 人工审阅与业务终点

Studio 与助手共用输入检查、计划、应用和采用端口。普通授权内连续调用沿当前范围执行；目标歧义、专项限制或实际需要作者决定时，提供方显示具体差异。保存与发行按作者实际授权的计划执行，应用编辑与正式保存保持可辨。

协作记录只存个人会话和结果引用，作品正文、素材索引及发行物由所属模块维护。产品接入说明见[在线手册](https://galcraft.dev/docs/zh-CN/studio-guide/)，实现入口为 `packages/collaboration/` 与 Studio MCP 适配。
