# 制作、候选与恢复

M10 是 Studio 内置制作核心，负责个人草稿、规划、冻结、调度、任务、候选和采用计划。M09 提供精确版本的操作与生成能力，宿主提供凭据、磁盘、进程和资源租约；M04 准备媒体，M02 应用作品修改。官方和外部能力进入相同目录与生命周期。

## 输入与冻结

作者可以从直接输入、选区、场景、素材用途或可选方案起步。制作草稿按用途保留输入、上下文、连接、模型、工作流、参数及返回位置。首次有意义编辑建立个人草稿，后续停顿、切换及正常退出按所属路径保存。草稿允许不完整值，提交前按实际操作校验；关闭视图保留已保存草稿。草稿属于个人状态，作品 dirty 集合由 M02 决定。

M10 显示实际发送文本、文件、目的地、模型、请求数量和可知费用。采用目标与发送上下文分别确定；改变采用目标保持原发送范围。服务或工作流改变时，提供方说明能力差异并保留作者输入；作者可修正、换回方案或明确排除本次不发送的参数。

计划冻结输入、来源版本、操作身份、提供方精确版本、连接配置、模型、工作流、方案和参数。连接设置更新只影响后续计划。凭据保留在个人宿主存储，草稿及配置引用凭据身份。提交先持久化任务及来源草稿关联，同一计划重复提交返回同一任务；继续修改已提交配置时创建新草稿。

连接检查区分网络可达、结构映射和真实生成。读取模型或检查 API 图保持 `notRun` 试生成状态；作者明确生成测试样例后，系统创建普通任务与候选。各用途、模型和绑定分别记录检查结果。

## 调度、等待与请求计数

M10 校验任务 DAG，依赖候选经选择后才调度后继。作者事先选择的 `firstValid` 仅选服务顺序中第一个完整且通过类型/引用检查的候选，作品采用继续经独立计划。失败阻断未完成后继，独立项继续。

并发池按 `connectionId` 共享。准入额度取待执行项与同连接占用项冻结 `concurrency` 的最小值；占用数加一满足额度时才发送。默认值为 1，同连接按创建顺序等待，不抢占在途任务。远端 queued/running 及恢复查询占槽；不同连接独立计数，本地透明化在当前活动制作服务内共享单槽。

`timeoutSecByPurpose` 默认文本 120 秒，图像、差分、语音、音乐与透明化各 600 秒。任务从冻结配置按用途取值；该值限制单次 HTTP 无活动等待，收到实际进度时续期。远端明确 queued/running 时，系统保留原身份并提供继续等待或取消。状态未知时先核实原请求。

M10 在发送前记录 submitting 和 attempt，接收远端身份后立即持久化。请求计数以实际发送及其所属调用事实为准；原任务查询、取回与恢复保留原计数。状态查询与产物下载可自动退避重试，生成 POST 由明确的新请求决定。服务已受理而响应丢失时，系统显示 unknown，保留待核实事实。

进度显示提供方实际阶段、完成数与总量。无总量时使用不确定进度；服务未报告费用时显示未知及请求数量。流式文字可作为部分结果审阅；媒体完整写入且经 M04 探测后才成为可用候选。

## 取消与恢复

| 动作或异常 | 提供方行为 |
|---|---|
| 关闭制作页面或客户端 | UI 解除订阅；宿主保留个人任务和服务生命周期 |
| 明确取消 | 停止未发送后继，按实际协议取消已发送项，分别报告 local 与 remote 结果 |
| 服务仅有全局中断 | 保留其他任务，报告逐任务取消能力不足；迟到结果仍可取回原任务 |
| 请求已受理后断线/重启 | 按原远端身份查询与取回，保留冻结配置和 attempt |
| 单个产物下载失败 | 重新取回该产物，保留已完成部分 |
| 无法查询且接收结果未知 | 显示具体待核实状态，作者检查服务，再决定明确新请求 |
| 429 或额度不足 | 保留任务，说明等待或恢复条件 |
| 磁盘不足 | 保留完成候选，暂停后续获取，提供目录和空间处理入口 |

ComfyUI 使用实际 `prompt_id` 查询 history 和声明输出；WebSocket 重连只恢复观察。队列取消删除该 prompt 并确认，运行中取消按实例实际逐任务能力执行。VoiceStudio、语音服务和其他适配器沿真实能力报告取消与取回。宿主保留作者独立启动的工具服务，由作者管理其生命周期。

同一服务实例的资源交接先等待自身任务形成实际停点；共享实例只执行能够确认作用范围的操作。关闭本地接收与远端停止计费分别报告。配置或输入变化形成新计划，原任务保留原请求及身份。

## 候选、采用与清理

候选保留完整产物、冻结输入、来源、源版本和派生关系。选择候选只改变任务选择。采用到作品时，M10 重新检查源版本并准备 M04 媒体，构造稳定身份绑定和关联修改，经 M03/M08 校验后取得 M02 编辑计划。源内容变化要求重新计划，以保护作者新修改。

```mermaid
flowchart LR
  C[候选与冻结来源] --> V[校验源版本和范围]
  V --> A[M04 准备不可变媒体]
  A --> P[M02 关联编辑计划]
  P --> E[应用 working / 一次撤销]
  E --> R[M04 确认与 M10 采用回执]
  R --> S[M02 正式保存]
```

M10 在采用前持久保存候选、计划预览和调用关联。M02 接受后，宿主确认 M04 准备文件并补齐采用记录；后续记录写入失败时，重开利用 M02 原回执补齐同一关联组。已接受的文件继续保留。

M02 应用成功后显示“已采用，未保存”；实际保存回执覆盖该版本后显示已保存；撤销关联组后按当前状态显示未采用。候选继续保留，采用中的文本、配音、差分与引用使用同一事务历史。候选试玩使用隔离 candidate 域。

清理先列文件、大小和派生关系。已被下游引用的原件与后继一起处理，或先解除依赖。已采用内容通过 M04 实际引用判断，删除任务或候选记录保留作品素材。候选导出显示正文与参考文件范围，移除凭据、认证头和个人服务路径；导入分配新的本机任务与候选身份，再匹配作品位置并提出编辑。

实现入口为 `packages/authoring/production/`；服务协议和专用参数由 `packages/generation-services/` 及精确提供方包维护。
