# Typed video operation

Install the SDK 0.1.0 tarballs into a separate npm project and run `npm run typecheck`, `npm run build`, `npm run check`, and `npm run pack`. The plugin stays at 0.1.0 and requires engine `^0.1.0` during local development; ordinary installation can refresh the same local version while active leases retain their loaded graph. Install the archive through Studio and enable its exact version in a work. Add the plugin generation connection with the local simulation URL, then choose **New production → 视频 · MiniMax H3 模拟 API**. Its public field editor saves only the personal M10 draft. Check the frozen input and destination before starting the task. Review/play the candidate before adopting it into the asset library or a background.

A public `fieldEditor` is optional. Operations without one use the host's generic fields and media controls for every declared input port, including required inputs, single selection or multiple additions, replacement and individual removal. References carry their `port`; changing one port preserves references assigned to others. Parameter and media changes save the personal draft and invalidate the previous send plan. Manifest 2, `contractVersion: 1`, operation data versions and schemaVersion 1 task/draft/candidate envelopes remain separate from package version 0.1.0; opening old records does not rewrite them or submit a new request.

Start the local service with `node simulation/server.mjs <evidence-directory> <ffmpeg.exe> 8199`. Each accepted request renders a fresh H.264 MP4 using the supplied duration, ratio, resolution and seed. The service records submission/query/fetch identities in `requests.ndjson`. It implements a deliberately simplified local API and does not invoke MiniMax, ComfyUI, model weights or a paid supplier.

The reference sources were inspected on 2026-10-16:

- [Comfy-Org T2V template](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_minimax_h3_t2v.json): `MinimaxHailuo03TextToVideoNode` → `SaveVideo`.
- [Comfy-Org R2V template](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_minimax_h3_r2v.json): `MinimaxHailuo03ReferenceNode`, optional image/video/audio reference inputs → `SaveVideo`.
- [Comfy-Org native workflow guide](https://github.com/Comfy-Org/docs/blob/main/tutorials/video/minimax/minimax-h3-native.mdx) and [node implementation](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_api_nodes/nodes_minimax.py).

Those JSON templates are editor workflows, not an API prompt. This adapter explicitly maps its fields `prompt/model/resolution/ratio/duration/seed/watermark` to node `23.inputs`, selects the reference node when image bytes are attached, and links node `8.inputs.video=["23",0]`. It sends `POST /prompt` once with the frozen attempt ID, polls `GET /history/:id`, downloads `GET /view/:id`, and cancels with `POST /cancel/:id`. Reference media is transferred as MIME plus base64 bytes, never as a server-readable local path. The local simulation currently exercises image references; video/audio R2V inputs and actual supplier compatibility are outside its verified contract.

The simulation deliberately flattens the editor's dynamic `model` object into those input fields and offers local `768P/1080P` render sizes. The inspected H3 API node groups prompt, resolution, ratio and duration inside its dynamic model selection and offers `768P/2K`; seed and watermark remain separate inputs. Its real upload, authentication, vendor request and response formats differ from this loopback contract. Do not send the simulated body directly to ComfyUI or MiniMax. The native workflow guide describes a separate model-weight workflow and informs the reference scope rather than this HTTP implementation.

Operation ID/version, definition, exact provider package, parameters and references remain frozen with each task and candidate. Disabling or removing a package preserves those records and files; restore the exact package to resume querying the original remote task. Runtime playback uses standard video assets, so the generation service is absent from Player artifacts.
