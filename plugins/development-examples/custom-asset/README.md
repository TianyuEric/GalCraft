# Vector shape asset type

This ordinary SDK 0.1.0 plugin declares `org.example.vector-shape/shape` through a DOM-free manifest-v2 definition. The plugin stays at 0.1.0 and requires engine `^0.1.0` during local development. Install the supplied SDK tarballs in a separate npm project, then run `npm run typecheck`, `npm run build`, `npm run check`, and `npm run pack`. Install the resulting archive through the normal plugin installation flow and enable its exact version in the work. Reinstalling the same version refreshes the local package; active leases retain their loaded graph until release. Manifest version, `contractVersion: 1` and `typeVersion` remain separate from the package version.

Import `examples/triangle.shape.json`. The referenced example uses the formal asset identity `Tex001`; replace it with a real asset ID in the work. Reference collection includes that asset in the release closure. Copy and backup restore rewrite both the versioned value and the source JSON identity. Unknown data, providers, and versions remain readable through the generic asset record and cannot be interpreted as an image.

Each immutable variant's `typeData.value` is the authoritative editable value. The imported `.shape.json` remains source provenance; editing creates a new variant and does not mutate the old source or fixed variant. The Canvas stage reads `typeData`, validates the exact package and data version, and releases its surface on disposal. The same runtime entry serves Web and Windows. Existing document, asset-index and snapshot envelopes remain at schemaVersion 1; opening older records preserves their original data without writing new envelopes.


The editor entry declares ordinary assetEditor, assetPreview and assetThumbnail contributions. Studio discovers them through the type descriptor. The library editor changes vertices, color and the formal texture reference through the M04/M02 revision-checked transaction; it creates an immutable active variant. The static canvas reads the authoritative typeData.value, so it previews edited variants without recompiling a story. Both preview and thumbnail return a disposal function. The declared color filter uses exact scalar matching.
