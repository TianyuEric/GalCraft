# org.example.complete

Install the supplied SDK artifacts with npm install <contracts.tgz> <plugins.tgz>, then run npm run typecheck, npm run build, npm run check and npm run pack. Load the package directory through Studio development loading, or install the generated .galplugin through the ordinary package installer.

The text provider posts its public input to the configured base URL and uses the host credential service. Use a service you control for protocol acceptance. Capability limits are explicit.
