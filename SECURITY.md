# Security reporting

GalCraft 0.1.0 is an early preview. During the 0.x series, maintainers apply fixes to the latest Studio release line. Reports should identify the exact Studio, engine and plugin versions involved.

Report a security vulnerability privately through [GitHub private vulnerability reporting](https://github.com/TianyuEric/GalCraft/security/advisories/new). Include a minimal reproduction and send credentials, private projects and sensitive exploit details only through that private channel.

For an ordinary bug, use a minimal, sanitized reproduction in the [public issue tracker](https://github.com/TianyuEric/GalCraft/issues). Include the operating system, steps, expected behavior and observed behavior. Maintainers handle reports as their early-preview maintenance capacity allows.
