This file identifies scope and notice locations rather than relicensing external material.

The Live2D preparation script copies the Framework into an adapter and retains SDK notices. The optional engine path can carry this adapter and its notices; imported Core and models remain independent inputs. An external-input design does not by itself establish publication permission. A distributor must determine the applicable [SDK publication license](https://www.live2d.com/en/sdk/license/), including the [Expandable Application conditions](https://www.live2d.com/en/sdk/license/expandable/), for the actual application before releasing a distribution that uses the SDK.
